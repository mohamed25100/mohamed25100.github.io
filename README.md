# Portfolio Mohamed Boucherba

Portfolio statique prêt pour GitHub Pages. Aucun build ni installation nécessaire.

## Publication
1. Créer un dépôt public `mohamed25100.github.io` sur GitHub (ou utiliser le dépôt existant).
2. Déposer **les fichiers à la racine** du dépôt (index.html, style.css, script.js, CV-Mohamed-BOUCHERBA.pdf), sans dossier parent.
3. Ouvrir Settings > Pages > Build and deployment > Deploy from a branch, sélectionner `main` et `/(root)`, puis enregistrer.
4. Visiter https://mohamed25100.github.io après le déploiement.

Si le site actuel utilise déjà ce dépôt, sauvegarder ses fichiers avant de les remplacer.

## Personnalisation
Modifier `index.html` pour les textes et liens, `style.css` pour les couleurs et `script.js` pour les interactions.

Les expériences et compétences sont issues du CV fourni. Les projets professionnels sont présentés sans divulguer de code ou d'informations internes.
